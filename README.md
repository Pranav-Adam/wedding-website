
# 💍 WedSync – Wedding Event Website

WedSync is a responsive and elegant wedding event website developed for Bhavana & Siddhesh. It provides guests with all essential wedding information, including event schedules, venue details, family introductions, photo galleries, and pre-wedding videos in one place.

## ✨ Features

- Responsive and mobile-friendly design.
- Elegant landing page with personalized wedding invitations.
- Dynamic wedding countdown timer.
- Beautiful photo gallery showcasing memorable moments.
- Pre-wedding video integration using Google Drive.
- Wedding event schedules for Engagement, Haldi, Wedding, and Reception.
- Google Maps integration for venue navigation.
- Dedicated section introducing both families.
- Contact section for guest inquiries.
- Smooth scrolling and fade-in animations.
- Animated falling flower petals.
- Modern UI with elegant typography and hover effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Google Maps
- Google Drive Embed Integration

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/WedSync.git
   ```

2. Navigate to the project folder:

   ```bash
   cd WedSync
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in VS Code.

## 🔒 Privacy & Security Notice

For security, privacy, and personal data protection reasons, the original wedding photographs, family pictures, and video files have not been uploaded to this public GitHub repository.

- Personal photographs are excluded.
- Family images are not publicly shared.
- Original video files are not included.
- Only the source code and project implementation are available for demonstration.

**Note:** Some gallery and video sections may not display correctly without the original media assets.
