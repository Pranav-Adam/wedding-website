💍 WedSync – Wedding Event Website

A responsive and elegant wedding event website designed to celebrate the beautiful journey of Bhavana & Siddhesh. WedSync provides guests with all essential wedding information, including event schedules, venue directions, family introductions, photo galleries, and pre-wedding videos in one place.

The website is designed with a mobile-first approach, elegant UI components, smooth animations, and interactive elements to deliver a memorable user experience.

🌟 Features
Responsive Design: Mobile-friendly layout optimized for desktops, tablets, and smartphones.
Elegant Landing Page: Beautiful hero section with wedding details and personalized invitations.
Wedding Countdown: Dynamic countdown timer displaying the remaining time until the wedding.
Photo Gallery: Responsive image gallery showcasing memorable moments of the couple.
Pre-Wedding Videos: Embedded Google Drive video previews for sharing pre-wedding memories.
Event Schedule: Dedicated section displaying wedding ceremonies, engagement, Haldi, and reception details.
Google Maps Integration: Interactive venue navigation using Google Maps.
Our Families: Dedicated section introducing the bride's and groom's families.
Contact Section: Displays contact information for guest inquiries.
Visual Animations: Smooth scroll-based fade-in effects and animated falling flower petals.
Modern UI: Elegant typography, glassmorphism effects, hover transitions, and aesthetic color combinations.

🔒 Media & Privacy Notice

For security, privacy, and personal data protection reasons, the original wedding photographs and video files have not been uploaded to this public repository.

Personal wedding photographs are excluded.
Pre-wedding video files are not included in the repository.
Private family photographs are not publicly shared.
The website source code and implementation are available for demonstration and educational purposes.

Note: The website's gallery and video sections require the original media assets to be added locally. Without these files, some media elements may not display.
